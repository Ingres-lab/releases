# Neo kernel 6.6.144 (`perf`) — 20261115

Kernel set for the POCO F4 GT / Redmi K50 Gaming (`ingres`): `boot.img`, `vendor_boot.img` and `vendor_dlkm.img`, built together. This is the kernel shipped in Neo 24.0 20261115.

## What's new
- **AutoFDO (profile-guided optimisation) ported to 6.6:** hot/unlikely/split text layout, `-ffunction-sections`, `-fsplit-machine-functions`; EL2 (nVHE), vDSO and EFI-stub objects excluded. Profile recorded on-device with CoreSight ETE. Kernel micro-benchmarks +13% / +6% / +7% (A510 / A710 / X2), instruction-cache misses on exec -23%.
- **GPU:** `CP_AHB_CNTL` is programmed for the whole gen7_0 family (Adreno 730), fixing the "AHB bus error" at GPU start.
- **Panel:** backlight restored when leaving doze on L10 panels (no full-brightness flash).
- `-mtune=cortex-a710` (measured: no effect, +2% image size).
- Recovery vendor ramdisk includes `hwid.ko` and `fts_touch_spi.ko`.
