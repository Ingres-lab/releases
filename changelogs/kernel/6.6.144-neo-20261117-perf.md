# Neo kernel 6.6.144 (`perf`) — 20261117

Kernel set for the POCO F4 GT / Redmi K50 Gaming (`ingres`): `boot.img`, `vendor_boot.img` and `vendor_dlkm.img`, built together. This is the kernel shipped in Neo OS 0.4 Beta.

## What's new
- **Lighter hardening.** Turned off four checks that cost time on every system call or kernel function: `HARDENED_USERCOPY` (`__check_object_size` was #5 in the AutoFDO profile), `MITIGATE_SPECTRE_BRANCH_HISTORY`, `RANDOMIZE_KSTACK_OFFSET` and `ARM64_PTR_AUTH_KERNEL`. Userspace pointer authentication stays on. Stack zero-initialization stays on because Qualcomm's IPA driver relies on it.
- **ThinLTO**, and a re-recorded **AutoFDO profile (v3)**. The profile now also covers the vendor modules (Adreno `msm_kgsl`, display `msm_drm` and `ntsync`), using the new opt-in `AUTOFDO_MODULES` Kbuild switch.
- **AOD wake flash fixed (L10 panel).** DCS `0x51` on this panel takes four bytes, and in hardware AOD the panel runs on the last two. Before leaving AOD, the driver now turns off panel dimming and loads the wake brightness into both halves, so the clock no longer flashes at the AOD level.
- **AOD stays up.** The display driver leaves AOD only when an AOD-flagged layer disappears.

## Measured (kbench, clocks locked, median of 7 runs, compared with 20261115)
| Test | Gain |
|---|---|
| System calls | +26% |
| ntsync (Wine / Proton) | +9–40% |
| Vulkan dispatch (GPU driver) | +9–20% |
| Cross-core wake-ups (sync-wake + game mode) | up to 6× |

18 of 21 benchmarks are faster on average across the A510 / A710 / X2 cores. Large reads from RAM-backed files are about 10% slower; this is being investigated.
