# Neo kernel 6.6.144 (`perf`) — 20261114

Kernel set for the POCO F4 GT / Redmi K50 Gaming (`ingres`): `boot.img`,
`vendor_boot.img` and `vendor_dlkm.img`, built together from
`kernel/xiaomi/sm8450` @ `6b77d0882077` with the Sony `msm-6.6` base, clang 22
and ThinLTO. This is the kernel shipped in Neo 24.0 20261114.

## What's new
- **ASB-2026-11-02** (November 2026 Android security bulletin) merged: 78 commits
  on top of ASB-2026-10-05.
- **Battery charge counter fixed:** the ADSP reports µAh, but the Xiaomi
  `qti_battery_charger` driver multiplied by 1000 (nAh), overflowing `intval`
  above ~2147 mAh. Above roughly 47% the charge counter went negative in Android
  and batterystats.
- **Panel:** the L10 backlight is restored when leaving AOD, so wake and
  notification pulses no longer flash at full brightness first; the requested
  flat/color-accuracy mode is kept across panel power-off.
- **EVA/CVP:** DSP-side dma-buf fds are resolved through the fastrpc HLOS tgid
  instead of the fastrpc process index.
- **RTL8812AU/8821AU/8814AU** USB Wi-Fi driver (aircrack-ng, monitor mode and
  injection) added to `vendor_dlkm`.
- Default qdisc is `fq` (BBR pacing) and the default zram compressor is `lz4`.
- `uname -v` starts with an English weekday so Settings shows the kernel build
  date instead of "Unavailable".

## Compatibility
- **Requires ROM 20261114 or newer** (`ro.build.date.utc >= 1794646967`): the
  modules were built against this ROM's vendor userspace.
- `perf` profile: KernelSU-Next v3.4.2, NTSync, WALT/EPSS, 120 Hz command mode,
  USB Wi-Fi monitor/injection, USB RNDIS, RTL-SDR (built, not auto-loaded),
  user namespaces/checkpoint-restore.

## Flash
The three images are one set — never flash a subset. Flash in this order into
one slot (`_a` or `_b`), then reboot:

1. `vendor_dlkm` (logical, `/dev/block/mapper/vendor_dlkm_<slot>`) — must fit the
   existing logical partition
2. `vendor_boot` (`/dev/block/by-name/vendor_boot_<slot>`)
3. `boot` (`/dev/block/by-name/boot_<slot>`)

Verify the zip's `sha256`/`size` and each image's `size`/`sha256` against
`manifest.json` before flashing.
